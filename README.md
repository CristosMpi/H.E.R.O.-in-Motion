# H.E.R.O.-in-Motion
H.E.R.O. in Motion is an open-source, multi-agent robotics framework for smart-city simulation, sustainability research, and STEM education. Includes hardware designs, firmware, and the HERO DNA coordination protocol for autonomous urban agents.

The project is designed for urban robotics research, environmental monitoring, transportation experiments, and classroom STEM learning.

Robotic Agents
EmberHalt

Fire-risk detection & mitigation using heat, gas, and ultrasonic sensors.

SurfaceX

Street-cleaning and waste-monitoring robot with IR navigation.

BloomBot

Smart-greenery maintenance using soil-moisture sensing and micro-irrigation.

AquaBot

Water-quality monitoring robot for turbidity and pH data.

HERO DNA Protocol

A lightweight UDP-based coordination protocol enabling:

Robot-to-robot communication

Live environmental data exchange

Task scheduling by a central “Mayor” node

Distributed decision-making within the model city
